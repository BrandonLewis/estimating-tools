Estimate Navigator, an Excel add-in

What it does

Estimate Navigator is a task pane for estimate workbooks. It has five tabs:

  • Items lists the bid items and opens each item's sheet.
  • Checks shows which workbook checks pass and fail, failing ones first.
  • Codes searches the cost codes and sets a task's code.
  • Insert adds crew rows and tasks from the workbook's templates.
  • Read back checks the workbook is ready and gives the exact command to read it back.

Requirements

Excel for Windows, Excel for Mac or Excel on the web, with support for ExcelApi 1.9.

Excel must be able to reach anvilrockroad.com, for the add-in's own files, and Microsoft's servers, for the Office.js library every Office add-in loads.

Sample workbook

Download a sample workbook, open it in Excel, then open Estimate Navigator from the Home tab.

Troubleshooting

  • The pane is empty. The workbook was not built by est-estimate and has no hand-built Summary index. Try the sample workbook to confirm the add-in works.
  • The pane says "Update Estimate Navigator". The workbook was built with a newer layout than this version of the add-in understands. Update the add-in, or ask your administrator to.
  • Read back needs a local copy. The read-back command runs in a terminal in the workbook's folder, so the workbook must be saved on this computer. If it is on OneDrive or SharePoint, sync it to this computer first.

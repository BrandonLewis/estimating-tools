# Temporary-barrier (K-rail) layout & estimating criteria — Caltrans

Distilled from two public Caltrans design memos: **Memo to Designers 14-19,
"Temporary Railing" (April 1990)** and **Bridge Design Memo 13.1, "Temporary
Barrier Systems" (December 2025)** — both downloadable from dot.ca.gov (the
a11y PDFs carry a text layer). BDM 13.1 reproduces MTD 14-19 in full as its
Appendix A, so the BDM alone contains both. **Verify against the current
editions before pricing** — these are agency documents that revise; every
number below is citable to a memo section, not a default to trust blindly.

## The transition date decides which memo governs (check it FIRST)

BDM 13.1 §13.1.4: for Temporary Railing (Type K) per MTD 14-19, "Design
engineers and contractors may continue to use this system on projects
advertised before January 1, 2027." Projects
advertised on or after that date must use the MASH barrier systems of
Table 13.1.4-1 / Standard Spec 12-3.20C instead. Read the bid's
advertisement date before quantifying ANY temporary railing — the wrong
side of this date changes the system, the lateral criteria, and the
quantities on a current bid.

## Longitudinal layout & the estimate formula (MTD 14-19)

- K-rail is required on BOTH sides of a vehicular opening through
  falsework, and wherever falsework stands within **12 ft** of a traffic
  lane.
- Run-length estimate per side of a two-way opening:
  **structure width + 150 ft approach at a 10:1 flare + 60 ft trailing.**
- Quantities land in **multiples of 20 ft** (the module length).
- Crash cushions: a **12-module array per installation**, required under
  the sub-150-ft approach condition (the memo's Figure 3 layout); the
  150-ft-minimum layout (Figure 2) requires none. Which figure applies is
  a layout decision — record it with the takeoff.
- Keep ~**2 ft clear** between the railing and any drop-off, or anchor the
  railing to the deck.

## Lateral criteria (BDM 13.1 — the MASH-era rules)

- §13.1.2 distinguishes **setback distance** (traffic-side toe → edge of
  traveled way) from **clear area width** (work-side toe → the protected
  hazard). The CLEAR AREA WIDTH is what governs falsework.
- Table 13.1.4-1, Temporary Railing (Type K), 24 in wide, distance to a
  falsework member: **7 ft freestanding / 4 ft with "2 stakes or 2 anchor
  bolts" / 3 ft with "4 stakes or 4 anchor bolts"** (the table's own row
  labels). The memo's notes warn the tables do NOT state the full
  anchorage requirements (stake/anchor counts, approach/departure) — pull
  those from the standard specs / Authorized Materials List before
  pricing the anchored options.
- Footnote (a) allows 2 ft less when measured to a falsework *footing*
  edge — but the memo itself says that allowance "is anticipated to be
  removed." **Do not lean on it** in a bid that outlives the current
  edition.

## Pricing posture

Anchoring buys clearance: tighter sites push from freestanding toward
staked/bolted railing — which changes the railing line item's unit work
(drilling, anchors, deck repair at removal) as well as the layout. Price
the anchoring method the clearance actually forces, not the one the
default detail shows, and carry the crash-cushion arrays as their own
counted item (they are per-installation, not per-foot).

# Apply HeavyBook workbook edits (renamed)

This skill is now **`apply-estimate-workbook`**: the same read, dry run,
confirm, `--commit` and refresh workflow, for a HeavyBook book and for any
other exchange pack's book (the pack is found from the book's stamp). Load
`apply-estimate-workbook` and follow it; nothing here is kept up to date.

This pointer is retired in the release after the one that introduced
`apply-estimate-workbook`.
